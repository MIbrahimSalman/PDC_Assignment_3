# Measured presentations

Two versions are available:

- `Group04_slides_extended.pdf`: seven slides, with a dedicated names/introduction
  slide followed by a separate experiment-setup slide and the five case studies.
- `Group04_slides.pdf`: exactly six slides for the assignment's stated limit.
  Its introduction uses separate member cards, a short machine line and five
  model labels instead of dense text columns.

Both versions are generated by `python tools/render_results.py`. The measured
case-study content is shared. The report PDF is preserved when its LaTeX source
exists. Figures use the report's semantic palette when those assets are available.

`Group04_slides.pdf` is generated by `python tools/render_results.py` and contains
exactly the six slides below. Charts come from the same measurements as the report.
The introductory roles are explicitly proposed, pending member confirmation.

Suggested rehearsal allocation: introduction 1 minute; cases 1–5 approximately
1 minute 45 seconds each; leave about 15 seconds for the handoff/close. Both
members must rehearse every case for questions. No backup slides are included.

## Structure

Target `Group04_slides.pdf` or `.pptx`: exactly six slides, no appendix.

1. Introduction: group, both names/roll numbers/responsibilities, machine, models.
2. Heat diffusion.
3. k-mer counting.
4. Monte Carlo.
5. PageRank.
6. Sample sort.

Each case slide needs a one-sentence problem/model, decomposition diagram, measured
scaling graph, one numerical insight or bottleneck, and a next experiment.
Rehearse a ten-minute talk with both members presenting, plus five minutes of questions.

The extended version is an alternative presentation, not an appendix to the
six-slide deck. Check which version your instructor permits before submission.
